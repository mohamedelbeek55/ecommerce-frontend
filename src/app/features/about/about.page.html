About This Project

ShopEase is a full-stack e-commerce portfolio project built to demonstrate end-to-end web application development — from a NestJS REST API with Prisma and PostgreSQL on the backend, to an Angular 21 frontend with Stripe payment integration.

Features include product browsing and filtering, a persistent shopping cart, authenticated checkout via Stripe Elements, order history, and an admin panel for managing products and categories. Authentication uses JWT access and refresh tokens with email verification.

This is a portfolio demo — no real goods are sold and no real payments are processed. Stripe is configured in test mode; use card number 4242 4242 4242 4242 with any future expiry and any CVC to simulate a successful payment.
